# Фото кабінету для головного банера

- `studio-hero-supplied.png` — наданий користувачем файл, збережений байт-у-байт, 1672×941. Походження попередніх обробок не встановлюємо за назвою файлу; використовуємо саме наданий варіант без додаткової ретуші.
- `hero-layout-reference.png` — зразок бажаної композиції з текстом і хедером; не використовується як фон готової сторінки.

Оригінали не публікуються. На початковому етапі для банера було підготовлено JPEG у `public/images/`: 1672px та 1280px зі збереженням повного кадру; mobile 706×941 — вертикальна ділянка з оригіналу, crop offset x=650, y=0. Форматування штатним sips, JPEG quality 84. Ретуші, AI-реконструкції й перефарбування під час цієї задачі не виконувалося. Затемнення — окремий CSS-шар на сайті.

Напрям наступних фото: теплі бежеві та коричневі тони, натуральні матеріали й м’яке світло. Зберігати оригінали; цей напрям не означає автоматичний дозвіл на ретуш чи реконструкцію нових файлів.
