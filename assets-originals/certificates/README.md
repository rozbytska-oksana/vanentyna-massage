# Оригінали сертифікатів

Покладіть сюди фото, скани або PDF сертифікатів Валентини в початковій якості. Зараз файлів сертифікатів у цій папці немає.

Ця папка не публікується на сайті. Оригінали зберігаються без змін. Після перегляду та погодження підготуємо лише потрібні зменшені копії для галереї, звіримо текст, орієнтацію й читабельність та підключимо їх у даних.

Не потрібно перейменовувати або попередньо стискати файли. Не завантажуйте сюди AI-відновлені документи замість оригіналів. Перед публікацією перевіримо персональні дані й дозвіл на показ.
