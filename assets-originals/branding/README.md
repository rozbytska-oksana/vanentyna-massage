# Знак із вивіски

`sign-reference.png` — фото вивіски, надане користувачем, збережене без змін. Використовується лише як референс; фотографію не показуємо декоративним блоком на сайті.

За запитом користувача рослинний знак відтворено у векторі без горизонтального обрамлення. Також прибрано розділювальну лінію біля знака в логотипі. Геометрія знака: `public/images/plant-mark.svg`. Це векторне відтворення за фотографією, не отриманий оригінальний файл із друкарні. Ботанічну назву рослини не стверджуємо.

Світлий і темний логотипи та SVG-фавікон містять ту саму геометрію. PNG й ICO рендеряться із SVG-фавікона браузером, без AI-генерації та без встановлення залежностей. Фон фавікона #f1e9dd, знак #603d2c.

Попередні варіанти збережено як `previous-logo-light.svg` та `previous-logo-dark.svg`. Папка з референсом і попередніми версіями не публікується.

## Архів SVG-логотипів із текстом — 18.11.2026

`logo-light.svg` і `logo.svg` перенесено сюди з `public/images/`: сайт їх більше не використовує (хедер зібраний з `plant-mark.svg` і HTML-тексту). Це єдині копії поточного логотипа з ім’ям, тому їх збережено, а не видалено. Текст у них набраний системними Times/Arial.
