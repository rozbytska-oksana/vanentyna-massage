# Фото Валентини

`valentyna-portrait-original.webp` — портрет, наданий 22.11.2026 (1086×1448, прозорі «мазкові» краї), збережений байт-у-байт. Краї прозорі (альфа-канал); на сайті фото показується цілком: `public/images/valentyna/portrait-{480,800,1086}.{avif,webp}` з альфою. Без ретуші й без збільшення, відтворюється `npm run images -- valentyna/portrait`. Це фото замінило попереднє в блоці «Про мене».

Попереднє фото (`valentyna-treatment-original.png`, 20.11.2026, робочий кадр із клієнткою) за запитом користувачки видалено 22.11.2026 разом із public-похідними `treatment-*` (оригінал переміщено в Кошик macOS).
