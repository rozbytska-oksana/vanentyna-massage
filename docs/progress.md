## Плавна поява блоків без «стрибка» — 24.11.2026

- Причина: блоки з `data-text-reveal` були видимі одразу після завантаження, а при появі у viewport WAAPI-анімація стартувала з `opacity: 0`, тож блок зникав і проявлявся знову.
- Виправлення: inline-скрипт у `<head>` (app.vue) ставить `reveal-ready` на `<html>` до відмальовування body. CSS у `_text-reveal.scss` приховує `[data-text-reveal]:not([data-revealed])` лише з `prefers-reduced-motion: no-preference`. `useTextReveal` ставить `data-revealed` і запускає анімацію в тому ж кадрі, тому прозорість монотонно росте від 0 до 1 (перевірено вибіркою кадрів).
- Атрибут замість класу `is-revealed`: Vue переписує `class` при оновленні `:class` (наприклад, у каруселі відгуків), і клас зникав би. SectionEyebrow і тести переведено на `[data-revealed]`.
- Запобіжники: без JS класу немає, і все видно. Якщо JS зламався, inline-скрипт через 3 с знімає `reveal-ready`. Без IntersectionObserver чи WAAPI клас знімається одразу. З reduced motion усі блоки одразу позначені видимими. Додано тест на відсутність «стрибка» (66 тестів).
