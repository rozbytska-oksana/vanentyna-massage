# Продукт

Україномовний сайт особистої масажної практики Валентини Нечипоренко, Хорошів, Україна. Аудиторія — люди, які шукають масаж у Хорошеві та хочуть познайомитися зі спеціалісткою, послугами й кабінетом перед зверненням.

Цілі: представити спеціалістку, всі послуги та ціни, кабінет, справжні відгуки, відео й навчання; створити основу локального SEO та допомогти перейти до дзвінка або переписки.

## Межі першої версії

Статичний сайт без власного бекенду, бази даних, CMS, авторизації, календаря, онлайн-оплати або форми із серверною обробкою. Запис ведеться вручну. Майбутня кнопка «Записатися» відкриватиме вибір підтверджених контактних каналів. Відкриття месенджера або дзвінка не означає надсилання повідомлення чи підтвердження запису.

Не вигадуємо контакти, відгуки, досвід, кількість клієнтів, рейтинги, кваліфікації чи медичні гарантії. Непідтверджений контент не публікується.

## Поточна задача

Перший етап каркаса завершено. Хедер і hero створено. Поточна задача — структура «Про Валентину», редактура наданого тексту та папки для оригіналів фото й сертифікатів. За новим запитом головний банер використовує надане фото реального кабінету, світлі тексти та прозорий хедер у бежево-коричневій гамі; попередня AI-ілюстрація прибрана з public. Шрифти поки системні. Подальші блоки реалізуються окремими задачами; чернетковий прайс залишається неопублікованим.
