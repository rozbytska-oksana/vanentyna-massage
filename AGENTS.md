# Правила репозиторію

- Спілкування й документація українською; ідентифікатори англійською.
- Працюй лише в межах поточної задачі. Зберігай користувацькі зміни, перед редагуванням перевіряй файли та Git-статус, обмежений цією папкою.
- Папка зараз усередині батьківського Git-репозиторію. Не запускай `git init` і не змінюй файли поза проєктом. Commit, remote, push і публікація потребують окремого запиту.
- Стек: Nuxt 4, Vue 3, TypeScript strict, SSR + SSG, npm. Node.js зафіксований у `.nvmrc`. Не вимикай SSR і не послаблюй типізацію для проходження перевірок.
- Встановлення та зміни залежностей виконує користувач, якщо явно не делегував це в поточній задачі. Lockfile змінює лише npm.
- Нові Vue SFC: template → script setup lang="ts" → style scoped lang="scss", порожній рядок між блоками. Форматування визначають Prettier та EditorConfig.
- Дані зберігай у типізованих локальних файлах, не в компонентах. Не додавай непотрібні компоненти, бібліотеки, store або бекенд.
- Нові класи — BEM; SCSS із `&`. Єдині ширинні breakpoints: medium 768px та x-large 1200px, через `@use` модуля `app/assets/styles/_breakpoints.scss`. Включення міксинів усередині відповідного селектора.
- Не змінюй затверджений дизайн самовільно. Користувач підтвердив бежево-коричневий преміальний напрям. Контентні секції залишаються світло-бежевими; новий затверджений hero — тепле фото реального кабінету з темним CSS-затемненням, світлим текстом і прозорим хедером. Без зелених акцентів; цей hero є явним винятком із попередньої заборони темних панелей. Точні токени, логотип і шрифти ще provisional.
- Не вигадуй контакти, фото, відгуки, кваліфікації, результати, рейтинги чи інші бізнес-факти. Чернетковий прайс не публікуй до перевірки; поля duration немає.
- Знак бренду — векторна рослина з наданої вивіски, без ліній обрамлення. Спільна геометрія: public/images/plant-mark.svg; світлий/темний логотип і фавікон узгоджені з нею. Не повертай попередню гілочку й не змінюй знак самовільно. Фото-референс зберігається лише в assets-originals/branding.
- Семантична розмітка, видимий `:focus-visible`, клавіатура, reduced motion; основний контент доступний без анімацій. Browser API лише в клієнтському lifecycle.
- Зберігай `noindex` технічної чернетки. Не додавай домен, canonical або структуровані дані без підтвердження.
- Перевірки: `npm run lint`, `npm run typecheck`, `npm run generate`, `npm run test:e2e`. Smoke-тест потребує Chromium і свіжого SSG-результату. Форматування: `npm run format`, `npm run format:check`; SSR-збірка: `npm run build`.
- Не запускай конкурентні Nuxt-процеси проти однієї `.nuxt`; не зупиняй чужі сервери. Повідомляй фактичні результати та блокери.
- Після суттєвих рішень оновлюй документацію та прогрес. Остання реалізована задача — контакти й футер за наданим референсом: Instagram, Facebook, Viber, телефон, карта будинку культури та замовлений підпис Created by Oksana (LinkedIn). Підтверджені посилання — у app/data/contacts.ts; не замінюй їх вигаданими. Кнопки запису відкривають вибір каналів, час підтверджується особисто. Рослинний знак із вивіски у логотипі та фавікон збережено. H1 зменшено, CTA приглушено-бежевий; фон банера нерухомий, mobile-масштаб 86% збережено. Користувач дозволив створити логотип за макетом. Попереднє AI-фото більше не використовується на сайті; оригінал і похідні збережено в assets-originals. Нові фотографії добирати в теплій бежево-коричневій гамі, не перефарбовувати й не реконструювати оригінали автоматично.
